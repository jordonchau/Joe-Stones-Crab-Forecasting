# Joe-Stones-Crab-Forecasting

Analyzed 4 years of monthly sales data in Excel to identify seasonal trends and growth patterns. Built a time series forecasting model using regression and seasonality adjustments to predict 2024 sales, and evaluated accuracy using MAD, MSE, and MAPE. Generated insights to support inventory planning, staffing, and promotional strategy decisions.
